# frp

`frp` 是一个围绕“服务端统一管理、客户端轻量执行”构建的正向代理平台。

它的目标不是把所有代理形态一次性塞进系统，而是先把一条最常用、最清晰、最容易验证的链路做好：在公网服务器上集中管理分组和隧道，让内网机器上的客户端连接上来，领取配置，并把外部访问稳定转发到内网服务。

## 这个项目解决什么问题

很多内网服务需要临时或长期暴露给外部访问，例如开发环境、测试环境、家庭网络服务、实验性系统、私有工具或某些跨网络调试场景。  
传统做法往往需要在每台客户端上维护配置文件，或者在服务器和客户端之间手工同步端口规则。  
一旦隧道变多、机器变多、端口需要调整，配置就容易分散、过期或互相冲突。

这个项目选择把配置中心放在服务端：

- 管理员在 `frps` 的 WebUI 中创建分组和隧道。
- `frps` 保存配置、检查冲突、维护运行状态。
- `frpc` 只用一个登录 `key` 连接服务端。
- 客户端上线后自动领取它所属分组的完整配置。
- 配置变更后，在线客户端可以跟随服务端热重载。

换句话说，客户端不再是一个需要长期维护复杂配置的节点，而是一个执行器；真正的管理入口、配置来源和运行态判断都收敛到服务端。

## 适合的使用场景

这个项目当前更适合下面这些场景：

- 把内网 TCP 服务映射到公网端口，例如 SSH、数据库测试实例、开发服务器或自建服务。
- 把内网 UDP 服务映射到公网端口，例如需要 UDP 入口的测试服务或局域网应用。
- 用一台公网服务器集中管理多组内网客户端。
- 通过 WebUI 创建、启停、调整隧道，而不是在客户端上手改配置。
- 希望服务端能看见分组和隧道的运行状态，并在端口冲突或绑定失败时给出清晰反馈。
- 希望证书、HTTPS、控制连接 TLS、隧道 TLS 这些安全材料能由服务端统一管理。

## 项目由哪些部分组成

### frps

`frps` 是服务端，也是整个系统的管理中心。

它负责提供 WebUI 和管理 API，保存分组、隧道和证书资产，接收 `frpc` 的控制连接，并在客户端确认配置后开放公网 TCP/UDP 入口。所有重要决策都尽量放在这里完成，包括登录认证、端口冲突检查、运行状态判断、隧道启停和在线热重载。

### frpc

`frpc` 是轻量客户端。

它启动时只需要知道服务端地址和一段登录 `key`。登录成功后，客户端从服务端领取配置，然后按照服务端下发的隧道规则转发本机或内网服务流量。它不提供本地管理页面，也不维护复杂本地配置。

### WebUI

WebUI 是这个项目面向管理员的主要入口。

当前 WebUI 已覆盖初始化、登录、分组管理、隧道管理、证书资产管理、入口证书绑定和基础状态展示。管理员可以通过页面完成大部分日常操作，不需要直接编辑数据库或手写客户端配置。

## 当前已经具备的能力

项目当前已经形成了一个可运行的最小闭环：

- 服务端托管配置，客户端上线后自动领取。
- 管理密钥初始化、登录、会话恢复和认证重置。
- 分组创建、启停、编辑、删除和登录 `key` 重置。
- TCP 单端口映射和连续端口范围映射。
- UDP 单端口映射和连续端口范围映射。
- 在线分组的整组配置热重载。
- 隧道状态展示，包括禁用、冲突、异常和启用。
- 跨平台统一的端口冲突检查。
- SQLite 和 MySQL 存储。
- WebUI 静态资源托管和子路径挂载。
- 证书资产的导入、粘贴、生成、下载、删除影响分析和绑定复用。
- 管理面 HTTPS、控制连接 TLS、隧道监听侧 TLS 和后端 TLS 的证书绑定基础能力。
- Go 单元测试、控制面稳定性测试和 Python 端到端回归脚本。

## 一个典型工作流

1. 部署并启动 `frps`。
2. 打开 WebUI，初始化管理密钥。
3. 创建一个代理分组，获得一次性展示的客户端登录 `key`。
4. 在内网机器上启动 `frpc`，使用服务端地址和该 `key` 登录。
5. 在 WebUI 中为这个分组创建 TCP 或 UDP 隧道。
6. `frps` 将配置下发给在线 `frpc`。
7. 外部用户访问公网服务器上的端口，流量被转发到内网目标服务。

这个流程里，客户端只负责“连上来并执行”。后续端口调整、隧道启停、证书绑定和状态查看都回到服务端完成。

## 快速体验

服务端：

```powershell
cd frps
go build -o ./frps.exe ./cmd/frps
.\frps.exe
```

`frps` 默认读取当前工作目录下的 `data/config.json`。默认管理入口为：

```text
http://127.0.0.1:7080
```

客户端：

```powershell
cd frpc
go build -o ./frpc.exe ./cmd/frpc
.\frpc.exe --server <frps-host>:7000 --key <proxy-group-key>
```

其中 `<proxy-group-key>` 来自 WebUI 创建或重置分组时的一次性展示。

更完整的本地运行、配置和测试说明请看文档入口。
