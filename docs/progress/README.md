# 进度归档

本目录只记录已经完成、已经收口、已经确认边界的跨轮进度。

当前轮执行仍只看：

- `docs/tmp/todo.md`

统一轮换、归档、`.gitignore` 检查和提交约定见：

- `docs/workflow.md`

## 归档规则

- 按日期归档到 `docs/progress/YYYY-MM-DD.md`。
- 同一天完成的多个子步骤，按时间顺序继续追加到同一天文件。
- 这里只记录已完成内容，不记录当前待办；当前待办只允许出现在 `docs/tmp/todo.md`。
- 如果历史修改缺少明确归档时间，可以参考 `git log` 选择最接近的日期补档，并在对应文件中注明“近似归档”。
- 如果当前总目标已经完成，必须先归档到本目录、再检查 `.gitignore`、提交稳定状态，最后清空 `docs/tmp/todo.md`。
