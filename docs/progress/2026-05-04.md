# 2026-05-04

## TCP 数据面从控制连接摘离完成归档

- 当前 TCP 唯一执行路径已收口为：
  - `control connection` 只负责登录、心跳、配置同步、UDP 和少量控制消息
  - `server.hello` 下发 `tcpWorkPoolSize` 和会话级 `tcpWorkSecret`
  - `frpc` 登录后预热 idle `tcp work connection`
  - 公网 TCP 进入后，`frps` 先拿 idle work conn，再通过 `stream.open / stream.opened` 完成一次性配对
  - 配对成功后，busy work conn 直接切 raw relay；不再走 `stream.data / stream.close`
- `frps/pkg/protocol` 已删除旧 TCP 控制数据面死表面：
  - `TypeStreamData`
  - `TypeStreamClose`
  - `StreamClose`
  - `MarshalStreamClose / UnmarshalStreamClose`
- `frps/internal/control/wiring/server_test.go` 已补一条当前缺口回归：
  - `TestServerClosesPublicTCPConnectionWhenNoIdleWorkConn`
  - 当前要求是“无 idle work conn 时直接关闭公网 TCP 连接，不回退到 control connection，也不残留 active stream”
- 旧的几段 `effective_ip` / reload 历史测试仍保留为 `t.Skip(...)` 占位，但内部旧 `stream.close` 断言已清空，不再污染当前协议口径。
