# 当前轮 Todo

- 进度归档索引：`docs/progress/README.md`

## 当前总目标

在不改动后端 API、认证语义、现有路由路径和已实现管理能力的前提下，重构 `frps/webui` 为更现代化、更清晰的管理面板布局。新界面需要统一视觉系统、梳理导航层级、提升概览页和管理页的信息密度与可读性，并同时保证桌面端与移动端可用。

## 子步骤

1. 信息架构与版式基线
   - 重新定义全局 shell、导航结构、页面层级，以及卡片、列表、表单、对话框的共用骨架。
2. 视觉系统与全局样式
   - 抽离颜色、字体、间距、圆角、阴影、状态色和响应式断点，建立统一的 design tokens 与基础样式约定。
3. 概览页重构
   - 将首页改造成真正的管理仪表盘，突出状态总览、关键入口、风险提示和快捷操作。
4. 分组管理页重构
   - 优化统计区、列表布局、操作区和 token 展示流程，提升管理效率和视觉一致性。
5. 隧道管理页重构
   - 优化协议/范围信息展示、编辑表单布局、状态反馈和空态表达。
6. 登录与初始化页重构
   - 统一认证页面视觉语言，使初始化、登录、异常提示和会话状态表达保持一致。
7. 收束与验收
   - 完成前端构建、响应式检查、临时文件清理、正式文档同步和进度归档。

## 当前轮边界

- 只做前端信息架构、视觉和交互层重构，不新增后端 API、数据库字段或控制面协议。
- 不改动现有认证流程、路由语义、分组管理能力、隧道管理能力和 token 使用模型。
- 继续沿用 Vue + Element Plus，不引入重型状态管理、低价值封装层或新的前端框架迁移。
- 页面表达必须严格基于当前真实能力，不把未来功能写成已实现入口。

## 当前唯一下一步

基于已落地的新版管理壳层，先只重构 `DashboardView.vue`：按通用页面骨架改造首页，收口系统状态、快捷入口和当前边界表达，去掉过时的 Phase 文案与“下一步工作”叙事，但暂不改 `ProxyGroupsView.vue`、`TunnelsView.vue`、`InitSecretView.vue`、`LoginView.vue`。
