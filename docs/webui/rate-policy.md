# 限速策略页面 UI 规范

更新时间：2026-05-01

本文档描述"限速策略"页面的前端设计规范。该页面独立于分组配置，专门管理限速策略及其隧道绑定关系。

## 1. 路由与命名

| 项目 | 值 | 说明 |
|------|-----|------|
| 页面标题 | `限速策略` | 导航文案、页面标题统一使用该名称 |
| 路由名 | `RatePolicy` | 前端内部路由标识 |
| 路由路径 | `/rate-policies` | 限速策略管理页路径 |
| 视图组件 | `RatePolicyView.vue` | 主管理页组件 |

## 2. 页面结构

参考分组配置页面布局，页面结构如下：

```text
┌──────────────────────────────────────────────────────────────┐
│  限速策略                                           [刷新]   │
├──────────────────────────────────────────────────────────────┤
│  已选中: production-limit | 模式: 独享 | 下行: 10 Mbps       │
│  上行: 5 Mbps | 绑定隧道: 3 条 [编辑][编辑绑定][删除]        │
├────────────────────────┬─────────────────────────────────────┤
│  策略列表  [新建策略]  │  绑定隧道（production-limit）        │
│  ┌──────────────────┐  │  ┌────────────────────────────────┐  │
│  │ [全部][共享][独享]│  │  │ 分组 隧道名称 协议 远端       │  │
│  │ production-limit │  │  │ web-group web tcp 8080        │  │
│  │ staging-limit    │  │  │ api-group api tcp 9090        │  │
│  │ shared-bandwidth │  │  └────────────────────────────────┘  │
│  └──────────────────┘  │                                     │
└────────────────────────┴─────────────────────────────────────┘
```

结构说明：

- 页面头部只有标题和刷新按钮。
- 策略相关操作集中在"已选中策略"的操作栏中。
- 内容区固定为左右双栏：
  - 左侧策略列表（窄栏，约 6/24）
  - 右侧绑定隧道列表（宽栏，约 18/24）
- 左侧策略列表顶部有筛选按钮组：全部 / 共享 / 独享。
- 双栏内容区采用 `grid + flex` 撑满剩余高度，列表底边随浏览器窗口高度自适应。

## 3. 策略管理

### 3.1 策略列表表格

| 列名 | 说明 |
|------|------|
| 名称 | 策略名称，点击整行即可选中 |
| 模式 | `独享` / `共享` Tag |
| 下行 | 下行速率，如 `10 Mbps` |
| 上行 | 上行速率，如 `5 Mbps` |
| 绑定 | 绑定隧道数量，如 `3` |

筛选功能：

- 筛选按钮组位于策略列表顶部，策略表格上方。
- 三个选项：`全部` / `共享` / `独享`。
- 默认选中 `全部`，不做筛选。
- 切换筛选后，策略列表立即更新，保持当前选中策略（若存在）。
- 若当前选中策略被筛选隐藏，自动取消选中状态。

### 3.2 策略操作栏

当选中策略后，顶部显示策略信息栏：

| 信息项 | 说明 |
|--------|------|
| 名称 | 策略名称 |
| 模式 | `独享` 或 `共享`，使用 Tag 展示 |
| 下行速率 | 如 `10 Mbps` |
| 上行速率 | 如 `5 Mbps` |
| 绑定隧道数 | 如 `3 条` |

操作按钮：

| 按钮 | 说明 |
|------|------|
| 编辑 | 打开编辑策略弹窗 |
| 编辑绑定 | 打开绑定隧道对话框，编辑当前策略最终绑定集合 |
| 删除 | 删除当前策略（有绑定时需确认） |

### 3.3 策略操作

- 新建策略：左侧面板头部按钮，使用 `el-dialog`
- 编辑策略：基于当前选中策略，在顶部操作栏中触发
- 编辑绑定：基于当前选中策略，在顶部操作栏中触发
- 删除策略：基于当前选中策略，在顶部操作栏中触发

删除策略时：

- 若该策略下仍有绑定隧道，前端直接提示"请先解绑或迁移后再删除"。
- 只有在无绑定时才允许进入删除确认。

## 4. 隧道绑定管理

### 4.1 绑定隧道列表表格

| 列名 | 说明 |
|------|------|
| 分组 | 隧道所属分组名称 |
| 隧道名称 | 隧道名称 |
| 协议 | `TCP` / `UDP` |
| 远端 | 单端口值 |

列表说明：

- 隧道来源：从所有分组的单端口隧道中选择绑定。
- 不显示端口范围隧道（不支持限速策略）。
- 未选中策略时，显示空态提示"请选择策略查看绑定隧道"。
- 已选中策略但无绑定时，显示空态提示"该策略暂无绑定隧道"。
- 绑定关系调整统一进入"编辑绑定"对话框处理；右侧列表只负责展示当前策略已经生效的绑定结果。

### 4.2 绑定操作

- 绑定关系编辑：右侧面板头部按钮"编辑绑定"，打开隧道选择对话框（购物车模式）
- 不再把"新增绑定""迁移绑定""解绑"拆成三套独立页面状态；统一在同一个购物车对话框里完成
- 对话框中的购物车表示"当前策略最终要持有的绑定集合"

隧道选择对话框（购物车模式）：

- 标题：`编辑绑定`
- 三栏布局：左侧隧道池 → 中间操作按钮 → 右侧购物车
- 右侧购物车在打开时默认预装当前策略已经绑定的隧道
- 左侧隧道池按分组用标签页组织，仍显示全部可参与限速策略的单端口 TCP / UDP 隧道
- 已经进入右侧购物车的隧道会直接从左侧列表移除，不再保留一份镜像状态
- 已绑定其他策略的隧道在左侧保留原策略标识，复选框禁用，同时提供"迁移"按钮
- 点击"迁移"后，该隧道进入当前策略购物车，并从左侧列表移除
- 从购物车移除时，按原始来源恢复左侧状态：
  - 原本绑定其他策略：回到左侧原位置，并恢复原策略标识与"迁移"入口
  - 原本未绑定任何策略：回到左侧未绑定状态
  - 原本属于当前策略：回到左侧"提交后解绑"状态，表示本次提交将把它从当前策略移除
- 底部显示当前购物车数量，并以购物车最终内容作为提交依据；购物车允许为空，空表示提交后当前策略不再绑定任何隧道

## 5. 状态与交互

### 5.1 选中状态

- 点击策略表格行后，左侧表格行高亮。
- 右侧绑定隧道列表立即切换为当前策略的数据。
- 顶部操作栏同步显示当前选中策略名称、模式、上下行速率、绑定隧道数。

### 5.2 认证与跳转

- 页面挂载时先调用 `/auth/state`。
- 未初始化跳转 `/init`。
- 未认证跳转 `/login`。

### 5.3 空态与错误态

- 无策略时：显示"暂无策略，请新建"
- 未选中策略时：显示"请选择策略查看绑定隧道"
- 已选中策略但无绑定隧道时：显示"该策略暂无绑定隧道，点击"编辑绑定"添加或调整"
- 加载失败时：显示错误文案和"重试"按钮
- 无可绑定隧道时：绑定对话框左侧隧道池显示"暂无可绑定的单端口隧道"
- 左侧没有剩余可编辑项时：绑定对话框显示"当前没有可继续加入该策略的单端口隧道"

### 5.4 操作反馈

- 成功：`ElMessage.success`
- 失败：`ElMessage.error`
- 删除策略、批量解绑或迁移等不可逆操作：`ElMessageBox.confirm`

### 5.5 管理模型

- 当前页面按"单管理员浏览器会话"模型设计，不为多浏览器并发编辑做协商。
- 绑定对话框中的购物车、中间迁移态和待解绑态只保留在前端本地内存。
- 后端不维护独立的策略编辑会话，不保存中间购物车状态。
- 点击确认时，前端只按最终购物车内容计算本次绑定、迁移和解绑结果，再提交给后端生效。

## 6. 表单设计

### 6.1 新建/编辑策略

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| 名称 | `el-input` | 是 | 策略名称 |
| 模式 | `el-select` | 是 | `独享` / `共享` |
| 下行速率 | `el-input-number` | 是 | 速率数值 |
| 下行单位 | `el-select` | 是 | `K` / `M`（默认） / `G` |
| 上行速率 | `el-input-number` | 是 | 速率数值 |
| 上行单位 | `el-select` | 是 | `K` / `M`（默认） / `G` |

表单布局：

```
┌─────────────────────────────────────┐
│ 名称: [___________________________] │
│                                     │
│ 模式: [独享 ▼]                      │
│                                     │
│ ─── 下行速率 ───                    │
│ 速率: [________] 单位: [M ▼]        │
│                                     │
│ ─── 上行速率 ───                    │
│ 速率: [________] 单位: [M ▼]        │
└─────────────────────────────────────┘
```

校验规则：

- 名称必填，前后端都需要 `trim`。
- 速率数值必须大于 0。
- 速率数值上限：单位 K 时最大 999999，单位 M 时最大 999，单位 G 时最大 99。
- 编辑模式下，模式不可更改（模式变更需删除重建）。

### 6.2 绑定隧道对话框（购物车模式）

对话框采用三栏布局，但语义固定为"编辑当前策略的最终绑定集合"，而不是左点一下右点一下就立即写后端：

```text
┌──────────────────────────────────────────────────────────────────────────────┐
│  编辑绑定                                                              [×]  │
├──────────────────────────────────────────────────────────────────────────────┤
│                                                                              │
│  ┌──────────┐  ┌──────────────────────┐  ┌────┐  ┌──────────────────────┐   │
│  │ web-group│  │ ☑ web     TCP 8080   │  │    │  │ 当前策略目标集合 (3) │   │
│  │ api-group│  │ ☐ api     TCP 9090   │  │    │  ├──────────────────────┤   │
│  │ db-group │  │ other-a   UDP 5353 [迁移]│ → │  │ web     TCP 8080 [移除]│  │
│  │ ...      │  │ other-b   TCP 2222 [迁移]│   │  │ ssh     TCP 2222 [移除]│  │
│  │          │  │ pending   TCP 7001   │  │    │  │ api     UDP 9000 [移除]│  │
│  │          │  │                   │   │    │  │                        │   │
│  │          │  │ [全选]             │  └────┘  │ [全选] [清空]          │   │
│  └──────────┘  └──────────────────────┘          └──────────────────────┘   │
│                                                                              │
├──────────────────────────────────────────────────────────────────────────────┤
│                               最终目标 3 条  [取消] [确认提交]              │
└──────────────────────────────────────────────────────────────────────────────┘
```

左侧分组标签页采用垂直布局，支持滚动：

- 标签页在左侧垂直排列，每个分组一行。
- 分组数量多时，左侧标签页区域可滚动。
- 当前选中的分组标签高亮显示。

#### 左侧：分组标签页 + 隧道池

左侧区域分为两部分：

| 元素 | 类型 | 说明 |
|------|------|------|
| 分组标签页 | `el-tabs` | 左侧垂直排列，每个分组一个标签，支持滚动 |
| 隧道列表 | `el-table` | 当前分组下仍可被编辑的隧道池 |
| 全选按钮 | `el-button` | 只选中当前分组下可直接加入购物车的隧道 |

分组标签页布局：

- 标签页在隧道列表左侧垂直排列（`tab-position="left"`）。
- 每个标签显示分组名称，超长名称自动省略。
- 分组数量多时，标签页区域显示滚动条。
- 当前选中的分组标签使用高亮样式。

隧道池表格列：

| 列名 | 说明 |
|------|------|
| 选择 | `el-checkbox`，只对未绑定或待解绑状态可选 |
| 隧道名称 | 隧道名称 |
| 协议 | `TCP` / `UDP` |
| 远端 | 单端口值 |
| 当前策略 | 若当前绑定其他策略，显示策略名称；若本次移出当前策略，显示 `提交后解绑`；否则显示 `-` |
| 操作 | 对绑定其他策略的隧道显示 `迁移` 按钮 |

左侧状态规则：

- 原本未绑定任何策略的隧道：可直接勾选并添加。
- 原本绑定其他策略的隧道：保留原策略标识，复选框禁用，但允许点击"迁移"加入购物车。
- 原本属于当前策略、但已从购物车移出的隧道：回到左侧并显示"提交后解绑"，允许再次加入。
- 已在右侧购物车中的隧道：不再在左侧显示。

#### 中间：添加按钮

| 按钮 | 图标 | 说明 |
|------|------|------|
| 添加 | `→` 或 `>` | 将左侧选中的可直接加入项移入右侧购物车 |

按钮交互：

- 左侧无选中项时，"添加"按钮禁用。
- 点击"添加"后，左侧选中项进入右侧购物车，并从左侧列表移除。
- "迁移"按钮不依赖左侧复选框，点击后直接把该隧道作为迁移项加入右侧购物车。

#### 右侧：目标集合（购物车）

| 元素 | 类型 | 说明 |
|------|------|------|
| 标题 | 文本 | `当前策略目标集合 (n)`，显示最终要保留的绑定数量 |
| 目标列表 | `el-table` | 当前策略提交后的目标绑定集合 |
| 全选按钮 | `el-button` | 选中右侧所有隧道 |
| 清空按钮 | `el-button` | 清空右侧所有隧道，表示最终解绑全部 |

右侧列表表格列：

| 列名 | 说明 |
|------|------|
| 选择 | `el-checkbox`，多选 |
| 分组 | 隧道所属分组名称 |
| 隧道名称 | 隧道名称 |
| 协议 | `TCP` / `UDP` |
| 远端 | 单端口值 |
| 来源 | `原本属于当前策略` / `新绑定` / `从 xxx 迁移` |
| 操作 | 行内"移除"按钮 |

移除恢复规则：

- 从其他策略迁移来的隧道：移除后回到左侧原位置，恢复原策略标识。
- 原本未绑定的隧道：移除后回到左侧未绑定状态。
- 原本属于当前策略的隧道：移除后回到左侧并显示"提交后解绑"。

#### 对话框规格

| 属性 | 值 |
|------|-----|
| 宽度 | `1000px` |
| 高度 | `600px`（内容区固定高度，列表可滚动） |
| 顶部距离 | `8vh` |
| 关闭方式 | 点击 × 或按 ESC 取消所有操作 |

区域宽度分配：

| 区域 | 宽度 |
|------|------|
| 分组标签页 | `140px`（固定） |
| 隧道池列表 | `320px`（固定） |
| 添加按钮 | `50px`（固定） |
| 已选列表 | `剩余空间`（flex: 1） |

#### 限制规则

- 只显示单端口隧道（`remote_type === 'single'`）。
- 打开对话框时，当前策略原有绑定先进入右侧购物车，因此默认不在左侧出现。
- 已绑定其他策略的隧道不允许直接勾选加入，只允许通过"迁移"入口进入当前策略购物车。
- 同一隧道不能重复添加到右侧已选列表。

#### 确认逻辑

点击"确认提交"时：

1. 允许右侧购物车为空；空购物车表示当前策略提交后不再绑定任何隧道。
2. 前端先根据"原始绑定集合 vs 当前购物车集合"计算：
   - 新绑定多少条
   - 迁移多少条
   - 从当前策略解绑多少条
3. 若本次包含迁移或批量解绑，可弹出一次总确认摘要，但不额外在后端创建中间编辑状态。
4. 确认后，前端按最终购物车内容向后端提交最终结果，关闭对话框。

## 7. 模式说明

### 7.1 独享模式（independent）

- 同一策略中的所有已绑定隧道各自持有独立的令牌桶。
- 每条隧道的限速参数相同，但互不争抢。
- 若绑定了 n 条隧道，累计总带宽为 `n × 单隧道速率`。

### 7.2 共享模式（shared）

- 同一策略中的所有当前在线并进入运行态的已绑定隧道共用一组令牌桶。
- 共享范围允许跨分组，也同时覆盖 TCP 和 UDP 单端口隧道。
- 离线分组当前不参与共享；后续上线并进入运行态后，会自动并入同一带宽池。
- 所有在线隧道争抢同一带宽池。
- 累计总带宽等于策略配置的速率。

## 9. API 对齐

### RatePolicy

```typescript
interface RatePolicy {
  id: number
  name: string
  mode: 'independent' | 'shared'  // 独享 / 共享
  downlink_value: number          // 下行速率数值
  downlink_unit: 'K' | 'M' | 'G'  // 下行速率单位
  uplink_value: number            // 上行速率数值
  uplink_unit: 'K' | 'M' | 'G'    // 上行速率单位
  tunnel_count: number            // 绑定隧道数量
  created_at: string
  updated_at: string
}
```

### TunnelBinding

```typescript
interface TunnelBinding {
  id: number                      // 隧道 ID
  group_id: number
  group_name: string              // 所属分组名称
  name: string                    // 隧道名称
  protocol: 'tcp' | 'udp'
  remote_start: number
  remote_end: number              // 单端口时等于 remote_start
  rate_policy_id?: number         // 当前绑定的策略 ID（用于绑定对话框显示）
  rate_policy_name?: string       // 当前绑定的策略名称
}
```

### 接口定义

| 接口 | 方法 | 返回 |
|------|------|------|
| `/rate-policies` | GET | `{items: RatePolicy[]}` |
| `/rate-policies` | POST | `{item: RatePolicy}` |
| `/rate-policies/{id}` | PATCH | `{item: RatePolicy}` |
| `/rate-policies/{id}` | DELETE | `{}` |
| `/rate-policies/{id}/bindings` | GET | `{items: RatePolicyBinding[]}` |
| `/rate-policies/{id}/bindings` | PUT | `{items: RatePolicyBinding[]}` | 按最终购物车结果整体提交 |
| `/tunnels` | GET | `{items: Tunnel[]}` | 前端结合策略和绑定列表聚合可绑定隧道视图 |

补充约定：

- 管理 API 不维护独立的"绑定编辑会话"或"购物车草稿"。
- 前端通过 `/tunnels` 和当前策略绑定列表聚合左侧隧道池与右侧购物车。
- 点击确认时，前端直接调用 `PUT /rate-policies/{id}/bindings` 提交最终购物车结果，由后端一次性完成绑定、迁移和解绑。

## 10. 交互细节

### 10.1 策略列表筛选

- 筛选按钮组使用 `el-radio-group` + `el-radio-button` 实现。
- 三个选项水平排列：`全部` | `共享` | `独享`。
- 当前筛选项使用 `type="primary"` 高亮。
- 切换筛选时保持列表滚动位置。

### 10.2 策略信息栏

- 信息项之间使用分隔线 `|` 或 `el-divider` 区分。
- 模式使用不同颜色 Tag：
  - 独享：`type="primary"`
  - 共享：`type="success"`
- 绑定隧道数显示为 `n 条`，点击可滚动到右侧隧道列表。

### 10.3 绑定隧道对话框（购物车模式）

- 对话框固定宽度 `900px`，内容区高度 `600px`。
- 左侧隧道池使用 `el-tabs` 按分组组织，每个分组一个标签页。
- 左侧和右侧表格都使用 `el-table`，支持多选。
- 中间添加按钮垂直居中，直接复用 `Element Plus` 图标组件。
- 打开对话框时，右侧购物车默认装入当前策略已经绑定的隧道。
- 左侧表格行可点击选中，选中后点击中间"添加"按钮移入右侧。
- 原本绑定其他策略的隧道显示原策略名称和"迁移"按钮，不通过普通勾选进入右侧。
- 右侧每行有独立的"移除"按钮；移除后按原始来源恢复左侧状态，不保留镜像副本。
- 右侧底部有"清空"按钮，可一次性清空目标集合；清空后的提交语义是"解绑当前策略的全部隧道"。
- 左右两侧底部各有"全选"按钮。
- 底部显示最终目标数量："最终目标 N 条"，数字实时更新。
- 购物车、中间迁移态和待解绑态只保留在前端本地；确认时以后端最终结果为准，不额外创建后端草稿状态。

标签页交互：

- 分组标签页在隧道池左侧垂直排列（`tab-position="left"`）。
- 分组按名称排序显示。
- 分组数量多时，标签页区域显示垂直滚动条。
- 切换标签页时，保留其他标签页的选中状态（不清空）。
- 已在右侧购物车中的隧道直接从左侧移除，不再保留左侧镜像行。
- 绑定其他策略的隧道在左侧保留禁用样式和原策略标识，但允许点击"迁移"。
- 右侧点击"移除"后，隧道按原始来源恢复到左侧对应分组。

### 10.4 删除策略确认

- 无绑定时：
  > 确定删除策略"xxx"吗？此操作不可恢复。
- 有绑定时：
  > 策略"xxx"仍绑定 N 条隧道，请先解绑或迁移后再删除。

## 11. 移动端适配

- 双栏在小屏幕下垂直堆叠。
- 策略列表在上，绑定隧道列表在下。
- 筛选按钮组保持水平排列，但字号适当缩小。
- 策略信息栏改为垂直布局，操作按钮左对齐。
- 绑定隧道对话框改为全屏弹窗：
  - 宽度 `95%`，高度 `90vh`。
  - 分组标签页改为顶部水平排列，可横向滚动。
  - 隧道池和已选列表改为上下布局。
  - 添加按钮保持水平居中。
  - 底部操作栏固定在弹窗底部。

## 12. 与分组配置页面的差异

| 方面 | 分组配置 | 限速策略 |
|------|----------|----------|
| 左侧列表 | 分组列表 | 策略列表（带筛选） |
| 右侧列表 | 当前分组的隧道 | 当前策略绑定的隧道（跨分组） |
| 新建弹窗 | 分组信息 | 策略信息（模式+速率） |
| 右侧操作 | 新建隧道（抽屉） | 编辑绑定（购物车对话框） |
| 删除联动 | 删除分组时隧道一并删除 | 删除策略前需先解绑或迁移 |

## 13. 边界约定

- 限速策略不从属于任何分组，是独立资源。
- 隧道必须先存在（在分组配置中创建）才能绑定到策略。
- 单端口隧道才能绑定限速策略，端口范围隧道不支持。
- 一条隧道最多只能绑定一个限速策略。
- 页面编辑中的购物车和迁移状态只在前端维护，后端不保存中间草稿态。
- 策略的模式创建后不可修改，需要删除重建。
- 速率修改后立即生效，不影响现有绑定关系。
