# 限速策略页面 UI 规范

更新时间：2026-05-01

本文档描述"限速策略"页面的前端设计规范。该页面独立于分组配置，专门管理限速策略及其隧道绑定关系。

## 1. 路由与命名

| 项目 | 值 | 说明 |
|------|-----|------|
| 页面标题 | `限速策略` | 导航文案、页面标题统一使用该名称 |
| 路由名 | `RatePolicy` | 前端内部路由标识 |
| 路由路径 | `/rate-policies` | 限速策略管理页路径 |
| 视图组件 | `RatePolicyView.vue` | 主管理页组件 |

## 2. 页面结构

参考分组配置页面布局，页面结构如下：

```text
┌──────────────────────────────────────────────────────────────┐
│  限速策略                                           [刷新]   │
├──────────────────────────────────────────────────────────────┤
│  已选中: production-limit | 模式: 独享 | 下行: 10 Mbps       │
│  上行: 5 Mbps | 绑定隧道: 3 条 [编辑][删除]                  │
├────────────────────────┬─────────────────────────────────────┤
│  策略列表  [新建策略]  │  绑定隧道（production-limit）        │
│  ┌──────────────────┐  │  ┌────────────────────────────────┐  │
│  │ [全部][共享][独享]│  │  │ 分组 隧道名称 协议 远端 操作  │  │
│  │ production-limit │  │  │ web-group web tcp 8080 [解绑] │  │
│  │ staging-limit    │  │  │ api-group api tcp 9090 [解绑] │  │
│  │ shared-bandwidth │  │  └────────────────────────────────┘  │
│  └──────────────────┘  │                                     │
└────────────────────────┴─────────────────────────────────────┘
```

结构说明：

- 页面头部只有标题和刷新按钮。
- 策略相关操作集中在"已选中策略"的操作栏中。
- 内容区固定为左右双栏：
  - 左侧策略列表（窄栏，约 6/24）
  - 右侧绑定隧道列表（宽栏，约 18/24）
- 左侧策略列表顶部有筛选按钮组：全部 / 共享 / 独享。
- 双栏内容区采用 `grid + flex` 撑满剩余高度，列表底边随浏览器窗口高度自适应。

## 3. 策略管理

### 3.1 策略列表表格

| 列名 | 说明 |
|------|------|
| 名称 | 策略名称，点击整行即可选中 |
| 模式 | `独享` / `共享` Tag |
| 下行 | 下行速率，如 `10 Mbps` |
| 上行 | 上行速率，如 `5 Mbps` |
| 绑定 | 绑定隧道数量，如 `3` |

筛选功能：

- 筛选按钮组位于策略列表顶部，策略表格上方。
- 三个选项：`全部` / `共享` / `独享`。
- 默认选中 `全部`，不做筛选。
- 切换筛选后，策略列表立即更新，保持当前选中策略（若存在）。
- 若当前选中策略被筛选隐藏，自动取消选中状态。

### 3.2 策略操作栏

当选中策略后，顶部显示策略信息栏：

| 信息项 | 说明 |
|--------|------|
| 名称 | 策略名称 |
| 模式 | `独享` 或 `共享`，使用 Tag 展示 |
| 下行速率 | 如 `10 Mbps` |
| 上行速率 | 如 `5 Mbps` |
| 绑定隧道数 | 如 `3 条` |

操作按钮：

| 按钮 | 说明 |
|------|------|
| 编辑 | 打开编辑策略弹窗 |
| 删除 | 删除当前策略（有绑定时需确认） |

### 3.3 策略操作

- 新建策略：左侧面板头部按钮，使用 `el-dialog`
- 编辑策略：基于当前选中策略，在顶部操作栏中触发
- 删除策略：基于当前选中策略，在顶部操作栏中触发

删除策略时：

- 若该策略下存在绑定隧道，确认文案会明确提示"绑定隧道会自动解绑"。
- 删除成功后，相关隧道的限速策略字段自动清空。

## 4. 隧道绑定管理

### 4.1 绑定隧道列表表格

| 列名 | 说明 |
|------|------|
| 分组 | 隧道所属分组名称 |
| 隧道名称 | 隧道名称 |
| 协议 | `TCP` / `UDP` |
| 远端 | 单端口或端口范围 |
| 操作 | 解绑按钮 |

列表说明：

- 隧道来源：从所有分组的单端口隧道中选择绑定。
- 不显示端口范围隧道（不支持限速策略）。
- 未选中策略时，显示空态提示"请选择策略查看绑定隧道"。
- 已选中策略但无绑定时，显示空态提示"该策略暂无绑定隧道"。

### 4.2 绑定操作

- 绑定隧道：右侧面板头部按钮"绑定隧道"，打开隧道选择对话框（购物车模式）
- 解绑隧道：隧道表格行内操作

隧道选择对话框（购物车模式）：

- 标题：`绑定隧道`
- 三栏布局：左侧隧道池 → 中间操作按钮 → 右侧已选列表
- 左侧隧道池按分组用标签页组织，支持多选
- 中间有"添加"按钮（向右箭头），将选中项移入购物车
- 右侧已选列表支持多选和删除
- 底部显示已选数量，确认后批量绑定

## 5. 状态与交互

### 5.1 选中状态

- 点击策略表格行后，左侧表格行高亮。
- 右侧绑定隧道列表立即切换为当前策略的数据。
- 顶部操作栏同步显示当前选中策略名称、模式、上下行速率、绑定隧道数。

### 5.2 认证与跳转

- 页面挂载时先调用 `/auth/state`。
- 未初始化跳转 `/init`。
- 未认证跳转 `/login`。

### 5.3 空态与错误态

- 无策略时：显示"暂无策略，请新建"
- 未选中策略时：显示"请选择策略查看绑定隧道"
- 已选中策略但无绑定隧道时：显示"该策略暂无绑定隧道，点击"绑定隧道"添加"
- 加载失败时：显示错误文案和"重试"按钮
- 无可绑定隧道时：绑定对话框左侧隧道池显示"暂无可绑定的单端口隧道"
- 所有单端口隧道已绑定当前策略时：绑定对话框显示"所有单端口隧道已绑定该策略"

### 5.4 操作反馈

- 成功：`ElMessage.success`
- 失败：`ElMessage.error`
- 删除策略、解绑隧道等不可逆操作：`ElMessageBox.confirm`

## 6. 表单设计

### 6.1 新建/编辑策略

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| 名称 | `el-input` | 是 | 策略名称 |
| 模式 | `el-select` | 是 | `独享` / `共享` |
| 下行速率 | `el-input-number` | 是 | 速率数值 |
| 下行单位 | `el-select` | 是 | `K` / `M`（默认） / `G` |
| 上行速率 | `el-input-number` | 是 | 速率数值 |
| 上行单位 | `el-select` | 是 | `K` / `M`（默认） / `G` |

表单布局：

```
┌─────────────────────────────────────┐
│ 名称: [___________________________] │
│                                     │
│ 模式: [独享 ▼]                      │
│                                     │
│ ─── 下行速率 ───                    │
│ 速率: [________] 单位: [M ▼]        │
│                                     │
│ ─── 上行速率 ───                    │
│ 速率: [________] 单位: [M ▼]        │
└─────────────────────────────────────┘
```

校验规则：

- 名称必填，前后端都需要 `trim`。
- 速率数值必须大于 0。
- 速率数值上限：单位 K 时最大 999999，单位 M 时最大 999，单位 G 时最大 99。
- 编辑模式下，模式不可更改（模式变更需删除重建）。

### 6.2 绑定隧道对话框（购物车模式）

对话框采用三栏布局，类似购物车交互：

```text
┌──────────────────────────────────────────────────────────────────────────────┐
│  绑定隧道                                                              [×]  │
├──────────────────────────────────────────────────────────────────────────────┤
│                                                                              │
│  ┌──────────┐  ┌───────────────────┐  ┌────┐  ┌─────────────────────┐      │
│  │ web-group│  │ ☑ web      TCP 8080│  │    │  │  已选隧道 (3)       │      │
│  │ api-group│  │ ☐ api      TCP 9090│  │    │  ├─────────────────────┤      │
│  │ db-group │  │ ☑ ssh      TCP 2222│  │ →  │  │ ☑ web      TCP 8080│[移除]│
│  │ ...      │  │ ☐ admin    TCP 8081│  │    │  │ ☑ ssh      TCP 2222│[移除]│
│  │          │  │ ☐ db      TCP 3306 │  │    │  │ ☐ db      TCP 3306│[移除]│
│  │          │  │                   │  │    │  │                   │      │
│  │          │  │ [全选]            │  └────┘  │ [全选] [清空]     │      │
│  └──────────┘  └───────────────────┘          └─────────────────────┘      │
│       ↑              ↑                            ↑                        │

│                                                                              │

│                                             已选 3 条  [取消] [确认绑定]    │
```

左侧分组标签页采用垂直布局，支持滚动：

- 标签页在左侧垂直排列，每个分组一行。
- 分组数量多时，左侧标签页区域可滚动。
- 当前选中的分组标签高亮显示。

| 元素 | 类型 | 说明 |

- 标签页在隧道列表左侧垂直排列（`tab-position="left"`）。
- 每个标签显示分组名称，超长名称自动省略。
- 分组数量多时，标签页区域显示滚动条。
- 当前选中的分组标签使用高亮样式。

隧道池表格列：

| 列名 | 说明 |
|------|------|
| 选择 | `el-checkbox`，多选 |
| 隧道名称 | 隧道名称 |
| 协议 | `TCP` / `UDP` |
| 远端 | 单端口值 |
| 当前策略 | 若已绑定其他策略，显示策略名称；否则显示 `-` |

#### 中间：添加按钮

| 按钮 | 图标 | 说明 |
|------|------|------|
| 添加 | `→` 或 `>` | 将左侧选中的隧道移入右侧已选列表 |

按钮交互：

- 左侧无选中项时，"添加"按钮禁用。
- 点击"添加"后，左侧选中项移动到右侧，并清除左侧选中状态。

#### 右侧：已选列表（购物车）

| 元素 | 类型 | 说明 |
|------|------|------|
| 标题 | 文本 | `已选隧道 (n)`，显示当前数量 |
| 已选列表 | `el-table` | 已选择待绑定的隧道，支持多选 |
| 全选按钮 | `el-button` | 选中右侧所有隧道 |
| 清空按钮 | `el-button` | 清空右侧所有已选隧道 |

已选列表表格列：

| 列名 | 说明 |
|------|------|
| 选择 | `el-checkbox`，多选 |
| 分组 | 隧道所属分组名称 |
| 隧道名称 | 隧道名称 |
| 协议 | `TCP` / `UDP` |
| 远端 | 单端口值 |
| 操作 | 行内"移除"按钮 |

#### 对话框规格

| 属性 | 值 |
|------|-----|
| 宽度 | `1000px` |
| 高度 | `600px`（内容区固定高度，列表可滚动） |
| 顶部距离 | `8vh` |
| 关闭方式 | 点击 × 或按 ESC 取消所有操作 |

区域宽度分配：

| 区域 | 宽度 |
|------|------|
| 分组标签页 | `140px`（固定） |
| 隧道池列表 | `320px`（固定） |
| 添加按钮 | `50px`（固定） |
| 已选列表 | `剩余空间`（flex: 1） |

#### 限制规则

- 只显示单端口隧道（`remote_type === 'single'`）。
- 已绑定当前策略的隧道不显示在隧道池中。
- 已绑定其他策略的隧道显示策略名称，仍可选择（确认时会提示）。
- 同一隧道不能重复添加到右侧已选列表。

#### 确认逻辑

点击"确认绑定"时：

1. 若已选列表为空，提示"请选择要绑定的隧道"。
2. 若选中的隧道中有已绑定其他策略的：
   - 弹出二次确认：`选中的 N 条隧道已绑定其他策略，绑定后将自动解绑原策略。是否继续？`
3. 确认后提交绑定请求，关闭对话框。

## 7. 模式说明

### 7.1 独享模式（independent）

- 同一策略中的所有已绑定隧道各自持有独立的令牌桶。
- 每条隧道的限速参数相同，但互不争抢。
- 若绑定了 n 条隧道，累计总带宽为 `n × 单隧道速率`。

### 7.2 共享模式（shared）

- 同一策略中的所有当前在线并进入运行态的已绑定隧道共用一组令牌桶。
- 共享范围允许跨分组，也同时覆盖 TCP 和 UDP 单端口隧道。
- 离线分组当前不参与共享；后续上线并进入运行态后，会自动并入同一带宽池。
- 所有在线隧道争抢同一带宽池。
- 累计总带宽等于策略配置的速率。

## 9. API 对齐

### RatePolicy

```typescript
interface RatePolicy {
  id: number
  name: string
  mode: 'independent' | 'shared'  // 独享 / 共享
  downlink_value: number          // 下行速率数值
  downlink_unit: 'K' | 'M' | 'G'  // 下行速率单位
  uplink_value: number            // 上行速率数值
  uplink_unit: 'K' | 'M' | 'G'    // 上行速率单位
  tunnel_count: number            // 绑定隧道数量
  created_at: string
  updated_at: string
}
```

### TunnelBinding

```typescript
interface TunnelBinding {
  id: number                      // 隧道 ID
  group_id: number
  group_name: string              // 所属分组名称
  name: string                    // 隧道名称
  protocol: 'tcp' | 'udp'
  remote_start: number
  remote_end: number              // 单端口时等于 remote_start
  rate_policy_id?: number         // 当前绑定的策略 ID（用于绑定对话框显示）
  rate_policy_name?: string       // 当前绑定的策略名称
}
```

### 接口定义

| 接口 | 方法 | 返回 |
|------|------|------|
| `/rate-policies` | GET | `{items: RatePolicy[]}` |
| `/rate-policies` | POST | `{item: RatePolicy}` |
| `/rate-policies/{id}` | PATCH | `{item: RatePolicy}` |
| `/rate-policies/{id}` | DELETE | `{}` |
| `/rate-policies/{id}/tunnels` | GET | `{items: TunnelBinding[]}` |
| `/rate-policies/{id}/tunnels` | POST | `{tunnel_ids: number[]}` | 绑定隧道 |
| `/rate-policies/{id}/tunnels/{tunnel_id}` | DELETE | `{}` | 解绑隧道 |
| `/tunnels/bindable` | GET | `{items: TunnelBinding[]}` | 获取可绑定隧道列表 |

## 10. 交互细节

### 10.1 策略列表筛选

- 筛选按钮组使用 `el-radio-group` + `el-radio-button` 实现。
- 三个选项水平排列：`全部` | `共享` | `独享`。
- 当前筛选项使用 `type="primary"` 高亮。
- 切换筛选时保持列表滚动位置。

### 10.2 策略信息栏

- 信息项之间使用分隔线 `|` 或 `el-divider` 区分。
- 模式使用不同颜色 Tag：
  - 独享：`type="primary"`
  - 共享：`type="success"`
- 绑定隧道数显示为 `n 条`，点击可滚动到右侧隧道列表。

### 10.3 绑定隧道对话框（购物车模式）

- 对话框固定宽度 `900px`，内容区高度 `600px`。
- 左侧隧道池使用 `el-tabs` 按分组组织，每个分组一个标签页。
- 左侧和右侧表格都使用 `el-table`，支持多选。
- 中间添加按钮垂直居中，使用 `→` 图标表示向右添加。
- 左侧表格行可点击选中，选中后点击中间"添加"按钮移入右侧。
- 右侧每行有独立的"移除"按钮，可直接单行移除回左侧隧道池。
- 右侧底部有"清空"按钮，可一次性清空所有已选隧道。
- 左右两侧底部各有"全选"按钮。
- 底部显示已选数量："已选 N 条"，数字实时更新。
- 确认绑定时，若选中的隧道已绑定其他策略，弹出确认提示：
  > 选中的隧道中，有 N 条已绑定其他策略，绑定后将自动解绑原策略。是否继续？

标签页交互：

- 分组标签页在隧道池左侧垂直排列（`tab-position="left"`）。
- 分组按名称排序显示。
- 分组数量多时，标签页区域显示垂直滚动条。
- 切换标签页时，保留其他标签页的选中状态（不清空）。
- 已在右侧已选列表中的隧道，在左侧对应分组中仍显示，但禁用选择框。
- 禁用的隧道行样式变灰，提示"已添加"。
- 右侧点击"移除"后，隧道返回左侧对应分组，恢复可选状态。

### 10.4 删除策略确认

- 无绑定时：
  > 确定删除策略"xxx"吗？此操作不可恢复。
- 有绑定时：
  > 确定删除策略"xxx"吗？该策略下有 N 条绑定隧道将自动解绑。此操作不可恢复。

## 11. 移动端适配

- 双栏在小屏幕下垂直堆叠。
- 策略列表在上，绑定隧道列表在下。
- 筛选按钮组保持水平排列，但字号适当缩小。
- 策略信息栏改为垂直布局，操作按钮左对齐。
- 绑定隧道对话框改为全屏弹窗：
  - 宽度 `95%`，高度 `90vh`。
  - 分组标签页改为顶部水平排列，可横向滚动。
  - 隧道池和已选列表改为上下布局。
  - 添加按钮保持水平居中。
  - 底部操作栏固定在弹窗底部。

## 12. 与分组配置页面的差异

| 方面 | 分组配置 | 限速策略 |
|------|----------|----------|
| 左侧列表 | 分组列表 | 策略列表（带筛选） |
| 右侧列表 | 当前分组的隧道 | 当前策略绑定的隧道（跨分组） |
| 新建弹窗 | 分组信息 | 策略信息（模式+速率） |
| 右侧操作 | 新建隧道（抽屉） | 绑定隧道（购物车对话框） |
| 删除联动 | 删除分组时隧道一并删除 | 删除策略时隧道自动解绑 |

## 13. 边界约定

- 限速策略不从属于任何分组，是独立资源。
- 隧道必须先存在（在分组配置中创建）才能绑定到策略。
- 单端口隧道才能绑定限速策略，端口范围隧道不支持。
- 一条隧道最多只能绑定一个限速策略。
- 策略的模式创建后不可修改，需要删除重建。
- 速率修改后立即生效，不影响现有绑定关系。
