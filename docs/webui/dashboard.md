# 仪表盘页面设计规范

更新时间：2026-04-20

本文档定义 `/dashboard` 页面的设计基线，包括页面定位、路由安排、信息分区结构、展示数据来源和边界约束。

---

## 1. 页面定位

仪表盘是用户登录后的首个信息中枢，承担以下职责：

| 定位 | 说明 |
|------|------|
| 信息概览 | 一屏内展示管理密钥状态、分组总数、隧道总数、关键状态分布 |
| 快速入口 | 提供常用操作的快捷入口（新建分组、新建隧道） |
| 导航锚点 | 作为首次登录后的默认落地页，替代原 `/proxy-groups` |

**核心目标**：提升首次登录后的信息获取效率，无需跳转即可掌握系统整体状态。

---

## 2. 路由安排

| 路由 | 页面 | 说明 |
|------|------|------|
| `/dashboard` | `DashboardView.vue` | 仪表盘页面，作为登录后默认落地页 |
| `/` | 重定向到 `/dashboard` | 根路径重定向目标调整 |
| `/proxy-groups` | `ProxyGroupsView.vue` | 保留为一级导航入口，用于完整管理 |

导航顺序调整：仪表盘作为侧边栏首项，代理管理为次项。

---

## 3. 信息分区结构

采用卡片式布局，按信息类型分区：

```
┌─────────────────────────────────────────────────────────────┐
│  概览                                                    │
├─────────────────────────────────────────────────────────────┤
│  ┌─────────────┐  ┌─────────────┐  ┌─────────────┐         │
│  │  分组总数   │  │  隧道总数   │  │  启用隧道   │         │
│  │     12      │  │     45      │  │     38      │         │
│  │  [+ 新建]   │  │  [+ 新建]   │  │             │         │
│  └─────────────┘  └─────────────┘  └─────────────┘         │
├─────────────────────────────────────────────────────────────┤
│  认证状态                                                    │
│  ├─ 管理密钥：已初始化                                       │
│  ├─ 会话有效期：剩余 11h 23m                                 │
│  └─ [退出登录]                                              │
├─────────────────────────────────────────────────────────────┤
│  分组概览                                                   │
│  ┌─────────────────────────────────────────────────────┐   │
│  │ 名称        │ Token ID      │ 隧道数 │ 状态    │ 操作 │   │
│  │ production │ abc123...     │   15   │ 启用    │ →   │   │
│  │ test       │ def456...     │    8   │ 启用    │ →   │   │
│  │ staging    │ ghi789...     │    5   │ 禁用    │ →   │   │
│  └─────────────────────────────────────────────────────┘   │
│                                              [查看全部 →]   │
└─────────────────────────────────────────────────────────────┘
```

### 3.1 统计卡片区

位于页面顶部，展示三个核心指标：

| 卡片 | 数据来源 | 说明 |
|------|----------|------|
| 分组总数 | `GET /api/v1/proxy-groups` 返回 `items.length` | 所有分组数量 |
| 隧道总数 | `GET /api/v1/tunnels` 返回 `items.length` | 所有隧道数量 |
| 启用隧道 | `GET /api/v1/tunnels` 过滤 `enabled === true` | 运行中的隧道数量 |

每个卡片包含：
- 指标名称（12px，次要文字色）
- 数值（28px，主要文字色，字重 600）
- 可选快捷操作按钮（如 "+ 新建"）

### 3.2 认证状态区

展示当前管理会话信息：

| 字段 | 数据来源 | 说明 |
|------|----------|------|
| 管理密钥状态 | `GET /api/v1/auth/state` | 显示已初始化/未初始化 |
| 会话有效性 | `GET /api/v1/auth/session` | 显示会话剩余有效时间或已过期 |

操作：
- 退出登录：调用 `POST /api/v1/auth/logout`

### 3.3 分组概览区

展示分组列表的精简视图：

| 列 | 说明 |
|----|------|
| 名称 | 分组名称 |
| Token ID | 前 8 位 + "..." |
| 隧道数 | 该分组下的隧道数量（前端过滤统计） |
| 状态 | 启用/禁用 Tag |
| 操作 | 跳转到代理管理页 |

限制：
- 最多显示 5 条记录
- 底部提供"查看全部"链接，跳转到 `/proxy-groups`

## 4. 展示数据来源

### 4.1 API 调用

仪表盘页面需要调用以下现有 API：

| API | 用途 | 调用时机 |
|-----|------|----------|
| `GET /api/v1/auth/state` | 获取管理密钥初始化状态 | 页面加载时 |
| `GET /api/v1/auth/session` | 获取当前会话信息 | 页面加载时 |
| `GET /api/v1/proxy-groups` | 获取分组列表 | 页面加载时 |
| `GET /api/v1/tunnels` | 获取隧道列表 | 页面加载时 |

### 4.2 数据处理

所有统计在前端计算：

- 分组总数：`proxyGroups.length`
- 隧道总数：`tunnels.length`
- 启用隧道数：`tunnels.filter(t => t.enabled).length`
- 各分组隧道数：按 `group_id` 分组统计

## 5. 边界约束

### 5.1 不做的内容

| 边界 | 原因 |
|------|------|
| 不新增后端 API | 仪表盘只消费现有数据，不扩展接口 |
| 不引入图表库 | 保持轻量，使用纯文本和 Tag 展示状态 |
| 不做实时刷新 | 页面加载时一次性获取，不轮询或 WebSocket |
| 不做在线客户端统计 | 当前 API 无此数据 |
| 不做流量/速率统计 | 当前后端无此能力 |

### 5.2 交互边界

- 页面以信息展示为主，操作收敛为跳转和退出登录
- 分组概览区不提供完整的 CRUD，仅展示和跳转
- 统计卡片的"新建"按钮跳转到对应管理页
