# frps 功能文档

## 1. 功能总览

`frps` 提供五类功能：

- 分组与接入管理
- 正向代理管理
- 反向代理管理
- 连接与流量观测
- 抓包、日志与审计

## 2. 分组与接入管理

## 2.1 分组管理

管理员可以：

- 创建分组
- 修改分组名称
- 启用或禁用分组
- 轮换 token
- 设置分组限速
- 设置最大在线客户端数

业务规则：

- 分组名全局唯一。
- token 不明文回显，只允许创建和重置时查看一次。
- token 采用 `tokenId.secret` 两段式结构。
- 服务端只保存 `tokenId + tokenSalt + tokenHash`。
- 禁用分组后，新的 `frpc` 登录必须被拒绝。
- 已在线客户端可以选择立即踢下线或等配置重载回收。

## 2.2 `frpc` 客户端来源 IP 黑白名单

作用对象：

- 连接 `frps:7000` 的 `frpc` 来源 IP。

支持规则：

- 单 IP
- CIDR
- allow
- deny

判定顺序：

```text
deny 命中 -> 拒绝
allowlist 模式且 allow 未命中 -> 拒绝
其他情况 -> 放行
```

功能要求：

- 拒绝登录时要返回明确原因。
- 拒绝事件要记日志并推送到 WebUI。
- 管理员可查看最近拒绝记录。
- token 格式非法、`tokenId` 不存在、加盐 hash 校验失败都必须拒绝登录。

## 2.3 公网隧道入口来源 IP 黑白名单

作用对象：

- 访问正向代理公网端口的公网来源 IP。

功能要求：

- 在建立转发前判定。
- 被拒绝连接不进入活跃连接列表。
- 拒绝事件需记录来源 IP、目标端口、匹配规则。

## 3. 正向代理管理

## 3.1 隧道类型

支持：

- TCP
- UDP

不支持：

- HTTP/HTTPS 作为正向代理特殊模式

## 3.2 单端口映射

例如：

```text
frps:20000 -> frpc local 127.0.0.1:22
```

要求：

- 端口不可冲突。
- 支持启用和禁用。
- 支持独立限速。
- 支持独立抓包开关。

## 3.3 端口范围映射

例如：

```text
20000-20009 -> 127.0.0.1:30000-30009
```

要求：

- 两边区间长度必须一致。
- 不允许区间交叉。
- WebUI 要能按范围录入和展示。
- 运行态可按单端口展开查看。

## 3.4 在线状态

隧道页面至少展示：

- 隧道名称
- 协议
- 端口或端口范围
- 所属分组
- 当前在线客户端
- 当前活跃连接数
- 当前实时上行/下行速率
- 抓包状态

## 4. 反向代理管理

## 4.1 TCP 反向代理

功能：

- 指定固定监听地址和端口
- 指定单个上游地址
- 支持启停
- 支持限速和抓包

## 4.2 HTTP 反向代理

功能：

- 指定监听端口
- 指定域名 `Host`
- 指定上游 HTTP 服务
- 支持多个域名共享同一监听端口

## 4.3 HTTPS 反向代理

功能：

- 指定监听端口
- 指定域名 `SNI`
- 指定证书
- 指定上游地址

要求：

- 证书修改后支持热更新。
- 同一监听端口下，不允许 `SNI` 冲突。

## 4.4 证书管理

管理员可以：

- 上传证书和私钥
- 查看证书基本信息
- 绑定到 HTTPS 反向代理规则
- 禁用不再使用的证书

系统应展示：

- 证书名称
- 绑定域名
- 到期时间
- 使用中的规则数

## 5. 连接与流量观测

## 5.1 在线连接列表

必须展示：

- 连接 ID
- 来源类型：正向或反向
- 协议
- 所属分组
- 所属隧道或反代规则
- 客户端 IP/端口
- 服务端入口 IP/端口
- 上游 IP/端口
- 打开时间
- 上下行字节数
- 上下行速率
- 当前限速值
- 抓包状态

## 5.2 实时速率统计

统计维度：

- 全局
- 分组
- 隧道
- 反向代理规则
- 单连接

更新方式：

- 首屏 REST 拉取
- 后续通过 WebSocket 增量更新

## 5.3 限速

管理员可配置：

- 分组限速
- 隧道限速
- 反代规则限速

系统要求：

- 连接展示最终生效限速值
- 配置变更后立即生效

## 6. 抓包与审计

## 6.1 抓包

支持：

- 对单个在线 TCP 连接发起抓包
- 对隧道或反代规则开启自动抓包

展示内容：

- 任务状态
- 抓包目标
- 开始时间
- 已写入大小
- 文件下载入口

## 6.2 审计日志

必须记录：

- 管理员登录
- 分组创建、修改、删除、禁用
- token 重置
- 隧道增删改
- 反代规则增删改
- 证书上传和绑定
- 抓包任务创建与结束
- 黑白名单拒绝事件

## 7. WebUI 页面

建议页面：

- 仪表盘
- 分组管理
- 隧道管理
- 反向代理
- 证书管理
- 在线连接
- 抓包中心
- 审计日志
- 系统设置

## 8. 典型流程

## 8.1 新建一个正向代理分组

1. 管理员创建分组。
2. 系统生成 `tokenId`、随机盐和明文 token。
3. 管理员配置 `frpc` 接入 IP 黑白名单。
4. 管理员配置隧道入口 IP 黑白名单。
5. 管理员创建一个或多个 TCP/UDP 隧道。
6. `frpc` 使用 `server + token` 登录领取配置。

## 8.2 新建一个 HTTPS 反向代理

1. 上传证书。
2. 创建 HTTPS 规则。
3. 选择监听端口和域名。
4. 绑定证书和上游。
5. 系统校验冲突并热加载。

## 9. 非功能要求

- 配置变更后默认 3 秒内完成生效。
- WebSocket 中断后前端可自动重连并恢复状态。
- 被拒绝连接可在日志中追溯。
- 连接列表刷新不能阻塞转发链路。
