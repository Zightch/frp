# frps 功能文档

## 1. 功能总览

`frps` 提供五类功能：

- 管理端认证
- 分组与接入管理
- 正向代理管理
- 反向代理管理
- 连接管理与流量观测
- 抓包、日志与审计

## 1.1 管理端认证

功能要求：

- `frps` 启动时必须检查本地 `auth.json` 是否存在。
- 如果 `auth.json` 不存在，管理面只能进入初始化态；除健康检查外，只允许用户设置管理密钥。
- 管理认证不使用数据库 `admin/admins` 表。
- `auth.json` 只保存管理密钥的 hash，不保存明文。
- 浏览器登录时先获取一次性盐和 challenge 标识。
- 浏览器本地先计算 `keyHash = sha256(secret)`，再计算 `proof = sha256(keyHash + salt)`，把 `proof` 发回服务器验证。
- challenge 必须短时有效、只能使用一次、验证完成后立即失效。
- challenge proof 比较必须使用常量时间算法。
- 登录成功后，服务端签发管理会话；REST API 和 WebSocket 复用同一会话。
- 删除本地 `auth.json` 后，服务端必须自动回到未初始化态，并立即使旧 challenge 与旧管理会话失效。

## 2. 分组与接入管理

## 2.1 分组管理

管理员可以：

- 创建分组
- 修改分组名称
- 启用或禁用分组
- 轮换 token
- 设置分组限速

业务规则：

- 分组名全局唯一。
- token 不明文回显，只允许创建和重置时查看一次。
- token 采用固定长度拼接结构：`token = tokenId + tokenSecret`，不使用 `.` 分隔符。
- 服务端只在分组记录中保存 `tokenId + tokenHash`。
- 首版建议 `tokenId` 使用 32 位小写 hex，`tokenSecret` 使用 64 位小写 hex。
- `tokenHash = sha256(tokenSecret)`，用于 challenge 登录校验。
- `tokenId` 和 `tokenSecret` 必须固定长度，格式非法直接拒绝。
- 禁用分组后，新的 `frpc` 登录必须被拒绝。
- 管理界面不展示任何 `maxclient` / `max_clients` 配置项；每个分组固定只有一个客户端槽位，由 `frps` 控制面保证。
- 同分组已有客户端在线时，新的 `frpc` 登录必须直接拒绝，不做顶号切换。
- 分组级配置保存成功后，需要把最新配置版本即时推送到该分组在线 `frpc`。

## 2.2 `frpc` 客户端来源 IP 黑白名单

作用对象：

- 连接 `frps:7000` 的 `frpc` 来源 IP。

支持规则：

- 单 IP
- CIDR
- allow
- deny

判定顺序：

```text
deny 命中 -> 拒绝
allowlist 模式且 allow 未命中 -> 拒绝
其他情况 -> 放行
```

功能要求：

- 拒绝登录时要返回明确原因。
- 拒绝事件要记日志并推送到 WebUI。
- 管理员可查看最近拒绝记录。
- token 格式非法、`tokenId` 不存在、challenge 过期、challenge 重放、响应校验失败都必须拒绝登录。

## 2.3 公网隧道入口来源 IP 黑白名单

作用对象：

- 访问正向代理公网端口的公网来源 IP。

功能要求：

- 在建立转发前判定。
- 被拒绝连接不进入活跃连接列表。
- 拒绝事件需记录来源 IP、目标端口、匹配规则。

## 3. 正向代理管理

## 3.1 隧道类型

支持：

- TCP
- UDP

不支持：

- HTTP/HTTPS 作为正向代理特殊模式

## 3.2 单端口映射

例如：

```text
frps:20000 -> frpc local 127.0.0.1:22
```

要求：

- 端口不可冲突。
- 支持启用和禁用。
- 支持独立限速。
- 支持独立抓包开关。

## 3.3 端口范围映射

例如：

```text
20000-20009 -> 127.0.0.1:30000-30009
```

要求：

- 两边区间长度必须一致。
- 不允许区间交叉。
- WebUI 要能按范围录入和展示。
- 运行态可按单端口展开查看。

## 3.4 配置热更新

管理员在 WebUI 修改正向代理配置后，系统必须区分两类行为：

- `frpc` 执行配置，例如隧道启停、协议、端口映射、本地目标。
- `frps` 本地策略，例如 ACL、限速、抓包开关。

系统要求：

- 保存配置并完成端口冲突校验。
- 立即更新 `frps` 运行态监听器和规则快照。
- 执行配置变更后，立即向对应在线 `frpc` 推送最新 `configVersion`。
- 本地策略变更后，只要求 `frps` 立即生效，不要求 `frpc` 感知。
- 不要求 `frpc` 重启。

行为要求：

- 新增隧道后，新入口立即可用。
- 修改本地目标地址后，新连接立即使用新目标。
- 修改 ACL 或限速后，新接入连接和后续转发立即按新策略执行。
- 禁用或删除隧道后，新连接立即拒绝。
- 已建立连接默认允许自然结束，不因无关配置变更被中断。
- WebUI 应显示该客户端当前已同步的配置版本和最近同步时间。

## 3.5 在线状态

隧道页面至少展示：

- 隧道名称
- 协议
- 端口或端口范围
- 所属分组
- 当前在线客户端
- 当前活跃连接数
- 当前实时上行/下行速率
- 抓包状态
- 已同步配置版本

## 4. 反向代理管理

## 4.1 TCP 反向代理

功能：

- 指定固定监听地址和端口
- 指定单个上游地址
- 支持启停
- 支持限速和抓包

## 4.2 HTTP 反向代理

功能：

- 指定监听端口
- 指定域名 `Host`
- 指定上游 HTTP 服务
- 支持多个域名共享同一监听端口

## 4.3 HTTPS 反向代理

功能：

- 指定监听端口
- 指定域名 `SNI`
- 指定证书
- 指定上游地址

要求：

- 证书修改后支持热更新。
- 同一监听端口下，不允许 `SNI` 冲突。

## 4.4 证书管理

管理员可以：

- 上传证书和私钥
- 查看证书基本信息
- 绑定到 HTTPS 反向代理规则
- 禁用不再使用的证书

系统应展示：

- 证书名称
- 绑定域名
- 到期时间
- 使用中的规则数

## 5. 连接管理与流量观测

## 5.1 在线连接列表

必须展示：

- 连接 ID
- 来源类型：正向或反向
- 协议
- 所属分组
- 所属隧道或反代规则
- 客户端 IP/端口
- 服务端入口 IP/端口
- 上游 IP/端口
- 打开时间
- 上下行字节数
- 上下行速率
- 当前限速值
- 抓包状态
- 关闭原因

功能要求：

- 支持按分组、隧道、协议筛选。
- 支持进入某个隧道查看该隧道的活动连接。
- 支持管理员对单条连接执行断开操作。

## 5.2 连接管理

管理员可以对在线连接执行“断开连接”。

要求：

- 按连接 ID 精确断开，不影响其他连接。
- 支持在连接列表和隧道详情页发起。
- 断开后需要把关闭原因标记为 `admin_terminated`。
- 断开动作必须写入审计日志。
- 前端应收到实时状态更新，不依赖手工刷新。

## 5.3 实时速率统计

统计维度：

- 全局
- 分组
- 隧道
- 反向代理规则
- 单连接

更新方式：

- 首屏 REST 拉取
- 后续通过 WebSocket 增量更新

## 5.4 限速

管理员可配置：

- 分组限速
- 隧道限速
- 反代规则限速

系统要求：

- 限速在 `frps` 数据面执行，`frpc` 不接收限速配置，也不感知服务端是否正在限速
- 连接展示最终生效限速值
- 配置变更后立即生效
- 限速表现必须尽量平滑，不接受秒级“攒额度再突发”的 PWM 式整形
- 限速统一按应用层 pacing 实现
- 不引入 Linux `tc` 等平台绑定的内核限速方案，以保证 `frps` 运行在 Windows 和 Linux 时都具备一致能力

## 6. 抓包与审计

## 6.1 抓包

支持：

- 对单个在线 TCP 连接发起抓包
- 对隧道或反代规则开启自动抓包

展示内容：

- 任务状态
- 抓包目标
- 开始时间
- 已写入大小
- 文件下载入口

## 6.2 审计日志

必须记录：

- 管理端初始化
- 管理端登录
- 管理认证重置（例如删除 `auth.json`）
- 分组创建、修改、删除、禁用
- token 重置
- 隧道增删改
- 反代规则增删改
- 证书上传和绑定
- 抓包任务创建与结束
- 黑白名单拒绝事件
- 管理员强制断开连接

## 7. WebUI 页面

建议页面：

- 初始化/登录页
- 仪表盘
- 分组管理
- 隧道管理
- 隧道详情页内显示当前连接，并提供断开入口
- 反向代理
- 证书管理
- 连接管理
- 抓包中心
- 审计日志
- 系统设置

## 8. 典型流程

## 8.1 新建一个正向代理分组

1. 管理员创建分组。
2. 系统生成固定长度 `tokenId`、`tokenSecret` 和完整明文 token。
3. 管理员配置 `frpc` 接入 IP 黑白名单。
4. 管理员配置隧道入口 IP 黑白名单。
5. 管理员创建一个或多个 TCP/UDP 隧道。
6. `frpc` 使用 `server + token` 登录领取配置。

## 8.2 新建一个 HTTPS 反向代理

1. 上传证书。
2. 创建 HTTPS 规则。
3. 选择监听端口和域名。
4. 绑定证书和上游。
5. 系统校验冲突并热加载。

## 9. 非功能要求

- 配置变更后默认 3 秒内完成生效并同步到在线 `frpc`，不要求重启 `frpc`。
- 单条连接的强制断开请求默认 1 秒内反映到在线连接列表。
- WebSocket 中断后前端可自动重连并恢复状态。
- 被拒绝连接可在日志中追溯。
- 连接列表刷新不能阻塞转发链路。
