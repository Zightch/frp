# frpc 功能文档

## 1. 功能边界

`frpc` 是一个极简客户端，功能边界明确如下：

支持：

- 接入 `frps`
- 领取配置
- 执行 TCP/UDP 转发
- 自动重连
- 上报状态和错误

不支持：

- 本地管理页面
- 本地复杂配置
- 反向代理
- 自定义访问控制

## 2. 启动功能

启动命令：

```text
frpc --server 1.2.3.4:7000 --token xxxxx
```

要求：

- `server` 不能为空
- `token` 不能为空
- 启动后立即尝试连接

## 3. 登录功能

`frpc` 必须：

- 从 `token` 固定长度截取 `tokenId` 和 `tokenSecret`
- 先发送只包含 `tokenId` 的登录开始请求
- 接收服务端临时盐 challenge
- 计算 `tokenHash = sha256(tokenSecret)` 并发送 `sha256(tokenHash + challengeNonce)`
- 上报自身版本和基础环境信息
- 接收登录结果

成功后：

- 进入在线状态
- 接收配置版本
- 开始心跳

失败后：

- 输出明确错误原因
- 按退避策略重试

## 4. 配置接收功能

`frpc` 需要接收：

- 分组标识
- 配置版本
- 隧道列表
- 心跳间隔

处理规则：

- 新配置版本覆盖旧版本
- 新配置应用后返回确认
- 已删除隧道不再接受新流
- 新增隧道立即可用
- 配置更新不要求重启 `frpc`
- 已存在连接默认允许自然结束
- 服务端 ACL、限速、抓包策略不属于 `frpc` 配置接收范围

## 5. TCP 转发功能

当服务端要求打开某个 TCP 流时，`frpc` 必须：

1. 找到对应隧道
2. 计算本地目标地址
3. 拨号本地 TCP 服务
4. 建立双向收发
5. 在异常时关闭并上报

补充要求：

- 如果服务端发送 `stream.close`，`frpc` 必须只关闭对应 stream，不影响其他工作流。

## 6. UDP 转发功能

`frpc` 需要支持：

- 接收来自 `frps` 的 UDP 会话流量
- 转发到本地 UDP 服务
- 收取返回数据并送回 `frps`
- 维护会话超时

## 7. 重连功能

触发条件：

- 控制连接断开
- 登录阶段异常
- 心跳超时

要求：

- 自动重连
- 使用退避策略
- 重连成功后重新同步配置

## 8. 状态与错误上报

至少需要上报：

- 登录成功
- 登录失败
- 配置接收成功
- 配置应用确认成功或失败
- 本地拨号失败
- stream 关闭原因
- 重连开始和成功

## 9. 运行限制

`frpc` 必须遵守以下限制：

- 不本地保存 token
- 不绕过服务端配置创建新隧道
- 不暴露本地 HTTP API
- 不在本地维护独立 ACL
- 不实现或感知服务端限速状态

## 10. 非功能要求

- 长时间运行稳定
- 断网后可恢复
- 在配置变更时不崩溃，也不因热更新而重启进程
- 在本地目标不可用时能明确报错
